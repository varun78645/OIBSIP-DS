# Iris Flower Classification Using Machine Learning

## Project Overview
This project uses Machine Learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

## Objective
To build and evaluate machine learning classification models using flower measurements.

## Technologies Used
- Python 3.13.2
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The Iris dataset is loaded directly from Scikit-learn. It contains 150 samples and 4 input features.

## Project Steps
1. Data loading and exploration
2. Exploratory Data Analysis (EDA)
3. Data visualization using pairplots and boxplots
4. Feature selection
5. Training and testing data split
6. Model training using Logistic Regression and Decision Tree
7. Model evaluation using accuracy, confusion matrix and classification report
8. Selection of the best-performing model

## Results
Both classification models were trained and evaluated. The model with the higher accuracy was selected as the best-performing model.

## Conclusion
The project demonstrates how machine learning algorithms can classify Iris flower species based on their physical measurements.
