# Oasis Infobyte Data Science Internship

This repository contains three Data Science projects completed as part of my Oasis Infobyte Data Science Internship.

## Projects

### 1. Iris Flower Classification

Builds a machine learning model to classify Iris flowers into different species using flower measurements.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

### 2. Unemployment Analysis with Python

Analyzes unemployment trends in India using data visualization and exploratory data analysis, including changes during the COVID-19 period.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn.

### 3. Sales Prediction Using Python

Predicts product sales based on advertising expenditure across TV, Radio, and Newspaper using machine learning models.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Tools Used

- Python
- Jupyter Notebook
- Visual Studio Code
- GitHub

## Objective

To gain practical experience in Data Science, data analysis, data visualization, and machine learning through hands-on projects.
