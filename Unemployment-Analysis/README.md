# Unemployment Analysis with Python

## Project Overview
This project analyses unemployment trends in India using Python. It explores regional unemployment rates, monthly trends, rural and urban differences, and the impact of the COVID-19 period.

## Objectives
- Analyse unemployment trends in India.
- Compare unemployment rates across different regions.
- Study monthly unemployment patterns.
- Compare rural and urban unemployment.
- Examine unemployment before and during/after COVID-19.
- Visualise relationships between numerical variables.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses two CSV datasets:
1. Unemployment in India.csv
2. Unemployment_Rate_upto_11_2020.csv

## Analysis Performed
- Data loading and cleaning
- Missing-value handling
- Statistical analysis
- Unemployment trend visualisation
- Regional unemployment comparison
- Monthly unemployment analysis
- Correlation heatmap
- COVID-19 period comparison
- Rural vs Urban comparison
- Labour participation analysis

## Key Findings
- Unemployment rates varied across different Indian regions.
- Haryana and Tripura showed relatively high average unemployment rates in the second dataset.
- The COVID-19 period showed changes in unemployment rates.
- Rural and urban unemployment patterns differed.
- Labour participation rates changed over the analysed period.
